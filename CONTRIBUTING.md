# Contributing to Wirq Music Bot

We welcome contributions from the community!

## Development Guidelines
1. Ensure all code is cleanly formatted and typed where appropriate.
2. Maintain strict branding consistency: Bot Name is **Wirq Music Bot**, Owner is **@wirq4**, Channel is **@wirqbots**, GitHub repository is **Hankarivirk/WirqMusicbot**.
3. All sensitive credentials must remain in `.env` and never committed.
4. When adding new messages, add translations to all locale files (`en.json`, `hi.json`, `pa.json`).
5. Verify changes locally with unit tests before opening a pull request.
